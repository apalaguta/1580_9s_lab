Алгоритм
Функция создания списка для интерактивного режима
Спрашивает у пользователя каким образом он хочет создать список
Если пользователь хочет создать список самостоятельно:
Просим ввести пользователя список пока список будет не пустым и все элементы списка не будут числами
Возвращаем список
Если же пользователь хочет, чтобы программа создала список:
Спрашиваем у пользователя сколько чисел будет в списке
Создаем список из случайных целых чисел, которые попадают в диапазон  [0;100]
Выводим список
Узнаем доволен ли пользователь списком
Пока пользователь не доволен списком:
Спрашиваем номер элемента, который нужно изменить, и значение, которое нужно туда вставить.
Если введенные данные от пользователя числа, и первое число натуральное и меньше чем длина списка:
Изменить значения списка и на значения, которые ввел пользователь.
Если нет:
Вывести- введены некорректные данные
Ввернуть список.


Сортировка пузырьком
Создаем счетчик сравнений равный 0
Создаем счетчик перестановок равный 0
Создаем счетчик проходов равный 0 
Пока количество проходов меньше длины списка:
        Проходим по списку сравнивая соседние элементы, увеличивая счетчик сравнений                         Если первый член  пары больше второго:
 Переставить их местами
Увеличить счетчик перестановок
Вернуть отсортированный массив, количество сравнений и перестановок


Сортировка расчёской
Создаем счетчик сравнений равный 0
Создаем счетчик перестановок равный 0
Считаем шаг, вычитая из длины списка 1
Пока шаг больше или равен 1:
        Проходим по списку сравнивая элементы с  шагом , увеличивая счетчик сравнений                         Если первый член  пары больше второго:
 Переставить их местами
Увеличить счетчик перестановок
        Уменьшить шаг в 1.3 раза
Вернуть отсортированный массив, количество сравнений и перестановок






Сортировка выбором
Создаем счетчик сравнений равный 0
Создаем счетчик перестановок равный 0
Проходим по списку и находим наименьший элемент не отсортированного списка: увеличивая счетчик сравнений
Если найденное значение стоит на первом месте не отсортированного списка:
        То меняем значение стоящие на первом месте с найденным наименьшем значением        Увеличиваем счетчик перестановок
Повторяем сортировку пока весь список не будет отсортирован
Вернуть отсортированный массив, количество сравнений и перестановок




Основная часть
Спрашиваем пользователя какой режим программы или выход
Если пользователь выбирает демонстрационный режим:
Спрашиваем пользователя сколько чисел будет в списке пока введенное количество 
не будет натуральным числом
Создаем список из случайных целых чисел в количестве введенным пользователем, которые попадают в диапазоне  [0;100]
Сортируем список пузырьковым расческой и выборочным способами 
Вывести отсортированный список, и таблицу с количеством перестановок и сравнений
Вывести методы сортировки у которых меньше перестановок и сравнений
Если пользователь выбирает интерактивный режим:
        Получить список от пользователя для интерактивного режима
Сортируем список пузырьковым, расческой и выборочным способами 
Вывести отсортированный список, и таблицу с количеством перестановок и сравнений
Вывести методы сортировки у которых меньше перестановок и сравнений
Повторить пока пользователь не захочет выйти из программы
